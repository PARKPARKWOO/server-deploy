# ads.txt — platformholder.site (루트 도메인)
#
# 이 파일 하나가 platformholder.site 의 **전 서브도메인**에 적용된다.
# wp-blog · trainer · 그 밖에 광고를 얹는 모든 사이트가 여기를 따른다.
#
# ── 왜 서브도메인마다 두지 않는가 (IAB ads.txt 스펙 v1.0.3) ───────────────────
#   · 루트가 `subdomain=` 으로 선언하지 않은 서브도메인의 ads.txt 는 **크롤조차 되지 않는다**
#   · 선언하면 그 서브도메인 파일이 루트를 **상속하지 않고 대체**한다
#   → AdSense 계정 1개로 전 사이트를 돌리므로 루트 하나로 충분하고, 사이트가 늘어도
#     이 파일을 건드릴 필요가 없다.
#
# ⚠️ `subdomain=` 을 추가하려는 사람에게: 그 서브도메인에 **지시자 없는 ads.txt** 가
#    있으면 "판매 권한자 없음" 이 되어 그 사이트 광고가 조용히 멈춘다.
#    선언하기 전에 해당 서브도메인 파일이 아래 줄을 그대로 갖고 있는지 확인할 것.
#
# ── 갱신 방법 ────────────────────────────────────────────────────────────────
# Swarm config 는 **불변**이다. 이 파일을 고치면 docker-compose.yml 의
# `apex_ads_txt_v1` 을 `_v2` 로 올리고(서비스 쪽 source 도 함께) 재배포해야 한다.
# 이름을 그대로 두고 내용만 바꾸면 **옛 내용이 계속 서빙된다.**
#
# 검증: curl -s https://platformholder.site/ads.txt
#       AdSense > 사이트 > ads.txt 상태 리포트
